Privacy policy

This policy describes the Daily Market Review desktop uploader and this application information website, maintained by earlcuabo for personal use.

Information the uploader accesses

The uploader reads a prepared market research report from the user's PC. Google authorization provides an access token and a refresh token so it can create and update its report file in the authorized Google Drive account.

It uses the https://www.googleapis.com/auth/drive.file scope. It reads metadata for its report file, including its identifier, name, checksum, sharing-independent browser link, and application marker. It does not request access to Gmail, contacts, calendars, or all files in Drive.

How information is used

Report content is uploaded to Google Drive so the user can access and review it. File metadata is used to update the intended report and confirm that its content matches the local copy. Tokens are used only to authenticate these operations.

The uploader does not sell Google user data, use it for advertising, or use it to develop or train generalized artificial-intelligence or machine-learning models. Daily Market Review's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and security

Google authorization credentials are stored on the PC using Windows encryption tied to the current Windows user. Access tokens are held in memory during requests. Report copies and non-secret delivery logs are stored locally. The report file is stored in the user's Google Drive account, and requests to Google's APIs use HTTPS.

The uploader creates the report without public sharing and does not change file-sharing permissions. Later access depends on the sharing settings the user controls in Google Drive. No security measure can guarantee protection against every risk.

Sharing and other services

The uploader sends the report and relevant authentication requests to Google. It does not send the report to a separate application-maintainer server.

If the user separately authorizes ChatGPT to access Drive and review the report, OpenAI will process the content under that service's terms, privacy policy, and the user's account settings. The desktop uploader does not create that connection or send the report to OpenAI itself.

This information website uses no application analytics, tracking scripts, forms, or Google sign-in. GitHub Pages hosts the website and may process visitor information, including IP addresses, under the GitHub Privacy Statement.

Retention, revocation, and deletion

Local report archives, logs, and encrypted authorization remain on the user's PC until removed by the user. The Drive report remains until the user deletes it. Google's file history, trash, and retention rules may retain earlier copies.

To stop access, revoke Daily Market Review in Google Account connections and disable the PC's daily task. The user can also remove the stored authorization from the PC and delete local reports and the Drive file. Revoking access alone does not delete existing reports.

Questions and policy changes

For privacy questions, open an issue on the information-site repository without including private data. This page will be updated if the application's data practices change; the date above identifies the latest revision.
